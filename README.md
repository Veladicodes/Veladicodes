## 👋 About

I build machine-learning systems that run **live**, not just in notebooks: streaming pipelines, GPU inference, agent frameworks you can replay and audit, and dashboards that make the output usable.

- 🛡️ Security + ML: GPU-accelerated network intrusion detection
- 🤖 Agents: deterministic orchestration with tracing, replay and adversarial tests
- 🔥 Applied AI: RAG and computer vision for emergency response
- 🎓 B.Tech student at VIT
